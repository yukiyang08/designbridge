# 換風格實驗的測試照片

這個資料夾 git 會追蹤。repo 是公開的：網路上找來的照片 commit 前先確認授權（自己拍的、CC0、CC BY 註明作者都可以），每張的來源記在下面的「照片來源」。

## 放法

- 直接把照片丟進來就好，jpg / png 都可以，長邊最好 1024 像素以上。
- 檔名隨意；想標用途可以用 `05_old_living.jpg` 這種格式（編號對照 `docs/experiments/PHOTO_RESTYLE_EXPERIMENT_PLAN.md` 第 3.1 節）。
- 避開有人臉、門牌、信件等個人資訊的照片。

## 建議涵蓋

| 編號 | 想要的照片 |
|---|---|
| 05 | 破舊老公寓客廳（壁癌、掉漆、舊磁磚） |
| 06 | 雜物多的雅房或套房 |
| 07 | 舊廚房（油污、舊流理台、瓦斯爐） |
| 08 | 舊浴室（舊磁磚、馬桶、洗手台） |
| 09 | 頂樓加蓋或斜屋頂、和室 |
| 10 | 客餐廳一體、兩面以上有窗 |
| 11 | 宿舍或系統床套房 |
| 12 | 光線昏暗或很亂的房間 |

不用剛好 8 張，多放幾張我再挑。
